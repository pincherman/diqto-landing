Connexion

Je ne reçois pas mon code
  1. Demandez un nouveau code dans Diqto.
  2. Utilisez uniquement le dernier code reçu.
  3. Si le SMS n’arrive pas, choisissez la récupération par email dans l’app.

Le code et le lien sont privés : ne les envoyez jamais au support.

Mon lien de récupération a expiré

Demandez un nouveau lien depuis Diqto, puis ouvrez-le sur le même iPhone si possible. Les anciens liens expirent volontairement et ne peuvent pas être réactivés par le support.

Abonnement iPhone

J’ai payé mais Diqto affiche encore Free
  1. Ouvrez Profil → Abonnement.
  2. Touchez Restaurer mes achats.
  3. Rouvrez l’écran après quelques instants si le plan ne change pas immédiatement.

Utilisez le même compte Apple que lors de l’achat. Apple recommande la restauration depuis l’app concernée : procédure officielle Apple.

Je veux résilier mon abonnement

Sur l’iPhone, ouvrez Réglages → votre nom → Abonnements → Diqto, puis choisissez l’annulation. Apple indique la date de fin ; l’accès reste actif jusque-là. Consultez la procédure officielle Apple.

Je veux demander un remboursement

La décision et le remboursement sont gérés par Apple. Connectez-vous sur Signaler un problème à Apple, choisissez la demande de remboursement et l’élément concerné. Diqto ajuste ensuite l’accès après confirmation Apple. Voir l’aide Apple.

Quels sont les tarifs ?
  • Free : 0 €.
  • Essential : 9 € TTC/mois en France.
  • Vocal Pro : 19 € TTC/mois en France.

Le prix local affiché par l’App Store avant confirmation fait foi et inclut les taxes applicables.

Ce que le support ne vous demandera jamais

  • un code reçu par SMS ou un lien de récupération ;
  • votre mot de passe, votre identifiant Apple ou votre carte bancaire ;
  • un reçu complet ou une capture contenant des données personnelles.

Toujours bloqué ?

Indiquez seulement le scénario, l’heure approximative, le plan affiché, le plan attendu et la version de Diqto. Joignez une capture uniquement si elle ne contient aucune donnée personnelle.
