Bien démarrer

Votre premier document Diqto, étape par étape.

Un devis, une note d’honoraires ou une facture de cours : préparez votre premier cas, trouvez la dictée dans l’app et contrôlez le document avant de le partager.

1

Installez Diqto et choisissez votre activité

Sur iPhone, installez Diqto puis connectez-vous. Renseignez votre métier et les informations de votre entreprise. Pour un artisan, le démarrage propose ensuite Ajoute ton premier client, puis ouvre un formulaire manuel. C’est normal : la voix se trouve dans l’onglet Créer.

2

Ouvrez Créer, puis Parler

Dans Créer, choisissez Parler pour la dictée ou Manuel pour saisir votre document. Autorisez le microphone si vous dictez et gardez une connexion réseau pour le traitement IA. Donnez la prestation, les quantités, les montants connus et les informations à vérifier.

Besoin d’un point de départ ?Copiez une trame de dictée adaptée à votre document. Les exemples sont fictifs ; aucun document n’est créé sur cette page.
3

Regardez ce que Diqto a compris

Après traitement, vérifiez Document à générer, puis utilisez Préparer pour ouvrir le document proposé. Contrôlez le destinataire, les lignes, les montants et les informations manquantes. Selon votre activité, le type de document et les champs diffèrent.

4

Relisez avant de partager

Après la création, ouvrez Relire le brouillon. Vérifiez l’aperçu PDF et corrigez les montants, les coordonnées et les libellés. Rien n’a encore été envoyé au client. Dans le parcours actuel, un nouveau brouillon enregistré compte dans le quota mensuel de documents Free ; sa création n’est pas un achat.

Trois trames pour préparer votre première dictée

Ces textes sont des aides à adapter, pas des résultats IA ni des documents prêts à envoyer. La copie reste sur votre appareil ; aucune trame n’est envoyée à Diqto depuis cette page.

Une facture de cours

Prépare une facture pour [élève ou client] : [nombre] cours de [activité] sur la période [dates], au prix de [montant] euros par cours. Vérifie le total, le destinataire et le régime de TVA avant validation. Ne lance aucun prélèvement.

Voir le parcours cours et abonnements

Votre essai est réussi si le document contient les bonnes lignes et les bons montants, et si vous pouvez le retrouver puis le corriger. Aucun temps gagné n’est présumé : comparez sur votre propre tâche.

Trois repères pour savoir si Diqto vous aide vraiment.

Vous avez moins retapé

Les informations déjà dites ou déjà connues n'ont pas dû être saisies une seconde fois.

Vous savez quoi faire ensuite

Le brouillon, l'information manquante ou la prochaine action sont clairement visibles.

Vous êtes resté maître du résultat

Rien n'a été partagé ou décidé sans que vous puissiez le relire et le modifier.
